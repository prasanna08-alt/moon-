# Beyond the Moon — fixed-frame cinematic scroll

A React + GSAP ScrollTrigger + Lenis space experience. The viewport stays fixed while scrolling drives cinematic scene transitions inside the frame (fade, zoom, depth shift), rather than sliding normal page sections through the viewport. Includes the soundtrack extracted from the provided reference video.

## Run locally

```bash
npm install
npm run dev
```

Use the local URL printed by Vite. Click **PLAY SOUND** to start audio; browsers require user interaction before playing audio.

## Build check

```bash
npm run build
```

The visuals are recreated in CSS/SVG and are not original source assets from the reference site.
